# Project artwork

The selected icon combines Applied Energistics 2 15.4.10's crafting monitor texture with Minecraft 1.20.1's Recovery Compass texture. Source pixels are retained under `source/`. The textures are layered and enlarged using nearest-neighbor scaling; the CurseForge version adds a warm scheduled-craft yellow background and dark GUI-style frame.

The composition is reproducible with `tools/build_artwork.ps1`. No generated artwork is used.
